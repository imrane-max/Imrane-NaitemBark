# Imrane Naitembark — Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run
Open `index.html` in a browser (internet needed for fonts and icons), or run `python3 -m http.server` here and visit http://localhost:8000.

## Edit
- `js/script.js`: set `CONFIG` (email, GitHub, Instagram, Discord, website) and edit the `PROJECTS` and `SKILLS` lists. Empty links stay inactive.
- `assets/images/`: the artwork was cropped from the reference screenshot. Replace `hero-character.png`, `morocco.png`, `logo.png` and the three project images with original, higher-resolution files using the same names.
- `css/style.css`: colors and spacing are CSS variables at the top.

## Notes
- Theme choice is saved in localStorage.
- There is no contact form because sending email needs a backend or a form service; the Email button uses `mailto:`.
